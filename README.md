# Advanced Quiz Management System

##  Overview

The Advanced Quiz Management System is a command-line Python application designed to test users' knowledge through a series of questions. The system evaluates answers, calculates scores and percentages, assigns grades, and provides performance feedback.

This project demonstrates the practical implementation of Python fundamentals, including loops, conditional statements, lists, dictionaries, string manipulation, and user input validation.

---

##  Features

* Interactive quiz interface
* Multiple quiz categories
* Case-insensitive answer checking using `.lower()`
* Input cleaning using `.strip()`
* Automatic score calculation
* Percentage calculation
* Grade assignment
* Performance feedback
* Play-again functionality
* User-friendly console interface

## 🚀 How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open a terminal in the project directory.
4. Run the program:

```bash
python quiz.py
```
